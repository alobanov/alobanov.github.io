{%- comment -%} Renders a 0–5 rating as five pip dots. Filled pip = full point, half-filled = 0.5, empty = unrated. Params: rating — number, or nothing at all (music and location entries) highlight — true for entries the author recommends {%- endcomment -%} {%- if include.rating -%} {%- assign _r = include.rating -%} {%- if include.highlight %}{% endif -%} {%- for i in (1..5) -%} {%- assign _half = i | minus: 0.5 -%} {%- if _r >= i -%} {%- elsif _r >= _half -%} {%- else -%} {%- endif -%} {%- endfor -%} {%- endif -%}
