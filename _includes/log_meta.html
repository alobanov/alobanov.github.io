{%- comment -%} Derives display metadata for one log entry. Param: log — a document from site.logs Sets: log_link_label Liquid assigns leak into the calling scope, which is how the values get back out. {%- endcomment -%} {%- assign log_link_label = include.log.link_label -%} {%- unless log_link_label -%} {%- assign log_link_url = include.log.link | default: "" -%} {%- if log_link_url contains "imdb.com" -%} {%- assign log_link_label = "IMDb" -%} {%- elsif log_link_url contains "opencritic.com" -%} {%- assign log_link_label = "OpenCritic" -%} {%- elsif log_link_url contains "maps.app.goo.gl" or log_link_url contains "google.com/maps" -%} {%- assign log_link_label = "Maps" -%} {%- elsif log_link_url contains "podcasts.apple.com" -%} {%- assign log_link_label = "Apple Podcasts" -%} {%- elsif log_link_url contains "open.spotify.com" -%} {%- assign log_link_label = "Spotify" -%} {%- elsif log_link_url contains "youtube.com" or log_link_url contains "youtu.be" -%} {%- assign log_link_label = "YouTube" -%} {%- else -%} {%- assign log_link_label = "Link" -%} {%- endif -%} {%- endunless -%}
